# Numbered list only

Do not add introductions, list headers, conclusions, or explanations outside the list.
Only valuable data should be in the numbered list.  
The list should be in reversed order from what you got. 
Use the following format for each row of the list:

* 1st - <Item 1> 
* 2nd - <Item 2> 
* 3rd - <Item 3> 
...
